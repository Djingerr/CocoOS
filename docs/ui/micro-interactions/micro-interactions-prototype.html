Les ressorts sont calculés physiquement sur cette page (raideur k, amortissement c). SpringAnimation de Qt ne prend pas ces valeurs directement, donc les réglages QML proposés sont un point de départ à caler à l'œil sur la dalle. Sur le RK3588S, anime surtout scale, opacity et x/y, et garde le flou loin de l'écran de stream.

Un seul anneau glisse d'une jaquette à l'autre, et la piste défile avec le même ressort pour que tout reste solidaire. L'œil suit un objet au lieu de chercher un contour qui apparaît ailleurs. A sur la jaquette active l'ouvre en plein écran pendant la connexion à l'hôte, B annule.

Spec et départ QML
  • anneau · translateX · ressort vif
  • piste · translateX · ressort souple · marge de 44 px aux bords
  • jaquette active · échelle 1,08 · les autres à 48 % d'opacité
  • reflet · balayage 950 ms ease-in-out, 520 ms après l'arrêt du focus
  • ouverture · clip-path de la jaquette vers plein écran · ressort souple
// Étagère : un seul anneau qui suit l'élément courant
ListView {
    id: shelf
    orientation: ListView.Horizontal
    spacing: 16
    interactive: false                  // pilotée à la manette
    highlightFollowsCurrentItem: false  // on anime l'anneau nous-mêmes

    Behavior on contentX {
        SpringAnimation { spring: Theme.gentleSpring; damping: Theme.gentleDamping }
    }
    onCurrentIndexChanged: {
        const it = currentItem, m = 44
        let x = contentX
        if (it.x - x < m) x = it.x - m
        if (it.x + it.width - x > width - m) x = it.x + it.width - width + m
        contentX = Math.max(0, Math.min(x, contentWidth - width))
    }

    highlight: Rectangle {
        width: 132 * 1.08 + 12; height: 176 * 1.08 + 12
        radius: 17; color: "transparent"
        border.width: 2; border.color: Theme.ink
        x: shelf.currentItem ? shelf.currentItem.x + 66 - width / 2 : 0
        y: (shelf.height - height) / 2
        opacity: shelf.activeFocus ? 1 : 0
        Behavior on x { SpringAnimation { spring: Theme.snappySpring; damping: Theme.snappyDamping } }
        Behavior on opacity { NumberAnimation { duration: Theme.microDuration } }
    }

    delegate: GameTile {
        width: 132; height: 176
        y: (shelf.height - height) / 2
        scale: ListView.isCurrentItem && shelf.activeFocus ? 1.08 : 1.0
        opacity: ListView.isCurrentItem || !shelf.activeFocus ? 1.0 : 0.48
        Behavior on scale { SpringAnimation { spring: Theme.snappySpring; damping: Theme.snappyDamping } }
        Behavior on opacity { NumberAnimation { duration: 220 } }
    }
}

Appui et appui maintenu

A appui courtA maintenu 0,9 s pour quitter

L'appui s'écrase en 90 ms et revient avec un ressort qui dépasse légèrement. Les actions destructives demandent un appui maintenu. Le remplissage démarre lentement pour éviter les accidents et se vide si tu lâches avant la fin.

Spec et départ QML
  • appui · scale 0,955 · 90 ms ease-out
  • relâche · retour à 1 · ressort rebond
  • maintien · 900 ms · affichage = progression^1,4
  • vidange · 280 ms · libellé inversé sous le remplissage
// Appui : écrasement rapide, retour avec rebond
Rectangle {
    id: btn
    signal activated()
    property bool down: false
    width: 220; height: 52; radius: 26
    color: Theme.ink

    states: State {
        name: "down"; when: btn.down
        PropertyChanges { target: btn; scale: 0.955 }
    }
    transitions: [
        Transition {
            to: "down"
            NumberAnimation { property: "scale"; duration: Theme.pressDuration; easing.type: Easing.OutCubic }
        },
        Transition {
            from: "down"
            SpringAnimation { property: "scale"; spring: Theme.bouncySpring; damping: Theme.bouncyDamping }
        }
    ]
    Keys.onPressed: (e) => {
        if (e.key === Qt.Key_Return && !e.isAutoRepeat) btn.down = true
    }
    Keys.onReleased: (e) => {
        if (e.key === Qt.Key_Return && !e.isAutoRepeat) { btn.down = false; btn.activated() }
    }
}

// Maintien : la progression monte pendant l'appui, redescend au relâchement
Item {
    id: hold
    signal confirmed()
    property real progress: 0
    property bool holding: false

    NumberAnimation on progress { running: hold.holding; to: 1; duration: 900 }
    NumberAnimation on progress {
        running: !hold.holding && hold.progress > 0
        to: 0; duration: 280; easing.type: Easing.OutCubic
    }
    onProgressChanged: if (progress >= 1) confirmed()

    Rectangle {   // remplissage ; y placer une copie du libellé en Theme.inkOnAccent
        width: parent.width * Math.pow(hold.progress, 1.4)
        height: parent.height; color: Theme.accent; clip: true
    }
}

Les chiffres défilent comme un compteur mécanique. En maintenant →, le pas accélère, marque un arrêt sur chaque préréglage (10, 20, 40, 80) puis repart. Au bout de la course, le curseur résiste comme un élastique et revient. Fonctionne aussi à la souris en glissant.

Spec et départ QML
  • chiffres · translateY d'une colonne 0–9 · ressort vif
  • pas · 1, puis 2 après 5 répétitions, puis 5 après 14
  • cran · arrêt de 260 ms sur un préréglage pendant le maintien
  • butée · élastique 16 px max · retour ressort rebond
// Un chiffre du compteur : colonne 0–9 qui défile
Item {
    property int digit: 0
    width: 26; height: 44; clip: true
    Column {
        y: -parent.digit * 44
        Behavior on y { SpringAnimation { spring: Theme.snappySpring; damping: Theme.snappyDamping } }
        Repeater {
            model: 10
            Text {
                height: 44; text: index; color: Theme.ink
                font.family: Theme.fontUi; font.pixelSize: 44; font.weight: Font.Medium
                font.features: { "tnum": 1 }   // chiffres tabulaires de Sora
            }
        }
    }
}

// Pas accéléré et crans sur les préréglages
property int repeatCount: 0
property real detentUntil: 0
readonly property var presets: [10, 20, 40, 80]

Keys.onPressed: (e) => {
    const dir = e.key === Qt.Key_Right ? 1 : e.key === Qt.Key_Left ? -1 : 0
    if (!dir) return
    repeatCount = e.isAutoRepeat ? repeatCount + 1 : 0
    if (Date.now() < detentUntil) return
    const step = repeatCount < 5 ? 1 : repeatCount < 14 ? 2 : 5
    let v = Math.max(5, Math.min(150, value + dir * step))
    for (const p of presets) {
        const crossed = (dir > 0 && value < p && v >= p) || (dir < 0 && value > p && v <= p)
        if (e.isAutoRepeat && crossed) { v = p; detentUntil = Date.now() + 260; repeatCount = 0; break }
    }
    value = v
}

// Pilule élastique : deux bords animés séparément
Item {
    id: seg
    property int current: 1
    property int dir: 1
    property real leftEdge: 0
    property real rightEdge: 0

    function select(i) {
        dir = i > current ? 1 : -1      // avant les bords, pour que les durées soient à jour
        current = i
        leftEdge = options.children[i].x
        rightEdge = options.children[i].x + options.children[i].width
    }
    Behavior on leftEdge {
        NumberAnimation {
            duration: seg.dir < 0 ? 260 : 420
            easing.type: seg.dir < 0 ? Easing.OutBack : Easing.OutCubic
            easing.overshoot: 1.2
        }
    }
    Behavior on rightEdge {
        NumberAnimation {
            duration: seg.dir > 0 ? 260 : 420
            easing.type: seg.dir > 0 ? Easing.OutBack : Easing.OutCubic
            easing.overshoot: 1.2
        }
    }
    Rectangle {   // pilule
        x: seg.leftEdge; width: seg.rightEdge - seg.leftEdge
        y: 4; height: parent.height - 8; radius: 14; color: Theme.ink
    }
    Row { id: options; /* trois libellés */ }
}

La pastille d'état, qui affiche l'hôte et la latence pendant le stream, s'ouvre en notification puis se referme seule. Le contenu n'arrive qu'une fois la forme lancée, avec un léger flou qui se dissipe. Une nouvelle notification remplace la précédente sans refermer l'île. B la referme.

Spec et départ QML
  • forme · largeur, hauteur · ressort souple · rayon 380 ms ease-out
  • contenu · +110 ms, 45 ms entre éléments, flou 4 → 0 px
  • remplacement · sortie 120 ms, rebond d'échelle 1,025
  • fermeture · automatique après 2,8 s
Rectangle {
    id: island
    property bool open: false
    color: "black"; clip: true
    width: open ? 340 : 156
    height: open ? 72 : 30
    radius: open ? 28 : 15
    Behavior on width  { SpringAnimation { spring: Theme.gentleSpring; damping: Theme.gentleDamping } }
    Behavior on height { SpringAnimation { spring: Theme.gentleSpring; damping: Theme.gentleDamping } }
    Behavior on radius { NumberAnimation { duration: 380; easing.type: Easing.OutCubic } }

    Row {
        id: content
        anchors.centerIn: parent
        opacity: 0
        states: State { name: "shown"; when: island.open; PropertyChanges { target: content; opacity: 1 } }
        transitions: [
            Transition {
                to: "shown"
                SequentialAnimation {
                    PauseAnimation { duration: 110 }
                    NumberAnimation { property: "opacity"; duration: 240; easing.type: Easing.OutCubic }
                }
            },
            Transition { from: "shown"; NumberAnimation { property: "opacity"; duration: 100 } }

}
