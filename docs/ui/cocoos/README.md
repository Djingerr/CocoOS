# Refonte CocoOS — pack pour Claude Code

Commence par `CLAUDE_BRIEF.md`. À placer dans le dépôt sous `docs/ui/cocoos/`.

- `CLAUDE_BRIEF.md` : mission, contraintes, correspondance avec le code existant, phases et portes.
- `SPEC.md` : écran par écran, jetons, sons, vibrations, commandes, navigation, questions ouvertes.
- `DESIGN_SYSTEM.md`, `tokens.json` : le système de design.
- `reference/` : 59 planches en PNG, HTML autonome et source ; 33 animations en MP4 et en planches de 12 images.
- `motion/` : minutage des sons et vibrations, motifs de vibration.
- `sounds/` : 68 sons, manifest, SoundBank de référence.
- `mock/`, `assets/`, `tools/` : données de test, images de base, outils de comparaison.
